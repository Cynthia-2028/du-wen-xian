## 14.0 一句话规则

> **五条功能轨（1 结构化速览 / 2 通读带读 / 3 质量评估 / 4 传播转化 / 5 跨篇综合），每轮只执行一条；拿到文献一律先弹菜单，由用户亲自输入数字选择——AI 不代选，哪怕用户的话已经点名了某条轨；轨间用 PID 衔接，已读内容不重复输出。**
>
> **五项不是同一层级**：1/2/3 是同一篇的三种**读法**（互斥）；4 是读懂之后的**语体转换**（依赖 1–3 的成果，可连着做）；5 的输入是**多篇**（需库内 ≥2 篇，不读本篇）。级别差异见 14.9。

## 14.1 强制菜单（mandatory triage gate）

**触发条件**：本技能被加载并拿到要读的文献（PDF/文本/DOI/引文）——**无条件触发，不存在豁免**。

**必须做的动作**：原样输出标准菜单（措辞可微调，五行功能与"输入数字"提示不可省）：

> 本 skill 具有五条功能轨：
> **1、输出结构化的结果**——快速了解文章及作者信息（导语 + 身份卡 + 核心主张 + 论证链条 + 发现 + 术语 + 800 字提炼）
> **2、通读论文**——带读摘要、关键段落和结论（逐段"原文 + 译文 + 解析"领读）
> **3、评估论文质量**——按论文类型路由评审框架，输出总评 + 检查表 + 红线单 + 修改优先级（P0/P1/P2）
> **4、传播转化**——推文 / 公众号摘要 / 演讲开场 / 邮件推荐 / 播客脚本（单人解说或双人对话）
> **5、跨篇综合**——库内多篇的共性、分歧与演进（**需库内 ≥2 篇；本项不读本篇**）
>
> 由于上下文长度限制，无法一次性输出五个结果，因此由你决定这次先看哪个：**输入数字（1 / 2 / 3 / 4 / 5）得到相应回答**。也可连选（如"2，然后 3"），将分轮逐轨交付。

**然后停止**。不得在菜单后附"我先默认给你轨 1"之类的预览，不得边问边做。

**各种输入情形的处理**：

| 用户输入 | 行为 |
|---|---|
| 什么都不输入（只加载技能、只给文献） | 发菜单，停下等数字 |
| "速览该论文" / "快速了解" / "作者信息" | 发菜单，可附"听起来像第 1 条，输入 1 确认"；**不得直接做** |
| "带我读这篇论文" / "通读" / "领读" | 发菜单，可附"听起来像第 2 条，输入 2 确认"；**不得直接做** |
| "评审 / 打分 / 研判质量" | 发菜单，可附"听起来像第 3 条，输入 3 确认"；**不得直接做** |
| "做个推文 / 写公众号 / 播客 / 演讲开场 / 推荐给导师" | 发菜单，可附"听起来像第 4 条，输入 4 确认"；**不得直接做** |
| "这几篇有什么共性 / 跨篇对比 / 我读过哪些 / 综述一下" | 发菜单，可附"听起来像第 5 条，输入 5 确认"；**不得直接做** |
| **一次给了 ≥2 篇文献** | 直接进轨 5（多篇只可能是跨篇），但先声明纳入篇数与深浅，不需弹单篇菜单 |
| 输入其他任何话语 | 发菜单，停下等数字 |
| 用户输入数字 1 / 2 / 3 / 4 / 5 | 执行对应轨（一次只出一轨） |
| 用户报 **5** 但库内不足 2 篇 | 不发综合，回：`库里现有 N 篇（列出），跨篇至少要 2 篇。你可以先读几篇，或者把要综合的文献一并给我。` |
| 用户连选（"2，然后 3"） | 先出先提到的轨，轨末提示"输入下一轨数字继续" |
| 同一文献已选定轨次后的追问 | 按当前轨继续正常执行，不重复弹菜单 |
| 换了一篇新文献 | **重新弹菜单** |

**核心原则**：**选择权始终在用户手里**。AI 的角色是呈现五条轨并等待指令；用户话语中即使含有明确指向（"速览""带我读""评审""做个推文"），也只能转化为菜单旁的确认提示，**绝不能转化为直接执行**。

**用户报的数字不在 1–5** → 礼貌重发菜单，不得自行解释成其他轨。

## 14.2 一次一轨（合并禁令）

1. **同一轮禁止合并两条及以上轨**——哪怕内容放得下。用户说"都要"时，回答："分轮给你，先出哪条？请报数字。"（或按用户已给顺序先出第一条）。
2. 一轨内部的完整性不受影响：轨 1 照 ch10 全模板、轨 2 照全文领读协议、轨 3 照 ch13 骨架，**不得因"只出一轨"而砍各轨内部的必要节**。
3. 单轨仍然超长 → 按 14.6 分册，附分册计划表。

## 14.3 段落锚点 PID（五轨公共资产）

PID 格式 `<部分字母>-<两位序号>`，写作 `[R-03 · p.812]`：

| 字母 | 部分 | 备注 |
|---|---|---|
| `A` | 摘要 | 轨 2 中 **100% 逐段全读** |
| `I` | 引言 | |
| `L` | 文献回顾 | |
| `M` | 研究设计 | |
| `R` | 实证分析 | |
| `D` | 讨论与结论 | |
| `O` | 其他（承担论证功能的脚注/图表说明/附录） | 须注明入选理由 |

规则：
1. PID 一经分配**不重编号**；跨轮续接，不从头再来。
2. 原文没有某部分 → PID 全空，注明"原文无此部分"。
3. **PID 是轨间衔接件**：轨 2 领读时必打；轨 1 / 轨 3 的事后引用一律 `→[PID]` 回指，不重抄原文；轨 3 的评审证据挂 PID 或页码。

## 14.5 跨轮衔接协议（切轨时做什么）

1. **轨 2 → 轨 1**：结构化速览的"位置"列直接 `→[PID]` 回指已领读段落；用户想看某段原文时引 PID 处原文（短引），不重新领读。
2. **轨 2 → 轨 3**：评审证据挂 PID（`→[R-05, p.815]`）；轨 2 的 PID 台账就是评审的"落实位置索引"。
3. **轨 1 → 轨 2**：领读不再重复导语（除非用户要求）；直接从摘要开始逐段讲。
4. **轨 1 / 轨 3 → 轨 3 / 轨 1**：已完成的结构化信息（身份卡、论证链）不重复输出，评审报告直接引用其节号（"见轨 1 §5"）。
5. **会话跨天/上下文丢失**：PID 台账不在上下文时，按需重新定位页码，不臆造 PID。
6. **轨 4 接前轨**：轨 4 的"事实内核对照表"**直接回指前面已产出的 PID**（`→[R-03]`），不重新读原文；若前面只跑过轨 1（无 PID），则对照表用页码，并注明"未领读，按页码核"。
7. **轨 5 接全库**：轨 5 不依赖本会话的 PID，依赖 `paper-library/` 的卡片；卡里的 PID 索引即为跨会话锚点。**会话内新领读的 PID 必须当场写入卡片**，否则下一个会话就丢了。
8. **轨 3 与轨 4 的顺序不建议颠倒**：先评过质量（知道这文哪里弱）再写宣传稿，边界段才写得实。反过来做，容易只写亮点。

## 14.6 长文档分册（单轨内部的容量管理）

1. 分册前先出**分册计划表**（各册覆盖的 PID 区间或章节），一次给全。
2. 每册末尾：本册已完成清单 + 尚未覆盖清单（"待续"）。
3. 最后一册给该轨的收尾件（自查表 / PID 台账 / 切换提示行）。
4. **禁止事项**：禁止交"节选版/预览版"当完整轨；禁止"下次再补"作为收尾；禁止跨册混入其他轨的内容。

## 14.7 违规形态（交付前自查排除）

| 违规形态 | 表现 | 处置 |
|---|---|---|
| **AI 代选**（v1.6 新列首位） | 用户说"速览""带我读""评审""做个推文"，AI 不弹菜单直接开做 | 停下，发菜单并附"听起来像第 X 条，输入 X 确认"；已产出内容保留但声明未经确认 |
| **不问就做** | 用户没输入任何话语，AI 直接开做某一轨 | 停下，发菜单等数字 |
| **多合一** | 一轮内同时给两条及以上轨（如结构化+领读+评审） | 拆轮：本轮等用户报数字，其余提示报数字 |
| **假菜单** | 发了菜单却接着自行输出内容 | 菜单后必须停止 |
| **轨内缺斤短两** | 借口"只出一轨"砍掉轨内必要节（如轨 1 没有导语、轨 2 没有译文、轨 4 没有对照表） | 按各轨章程补全；实在超长走分册 |
| **跨轨重复抄写** | 切轨后重抄大段原文 | 改为 `→[PID]` 回指 |
| **幽灵 PID** | 回指了从未领读过的 PID | 重新定位页码或如实说明"该段未领读" |
| **轨 4 事实漂移** | 宣传件里数字被改写、样本被升格、相关变因果 | 回原文核对，改回口径并在对照表标注（ch15 §15.7） |
| **轨 4 无对照表** | 交了文案没有"事实内核对照表" | 视为未完成，补齐再交 |
| **轨 5 串味** | 把 A 文的结论安到 B 头上，或抹平两文差异 | 回卡片/原文核对，改回并标来源（ch16 §16.9） |
| **轨 5 假库** | 声称"你读过 X"，实际库里没有 | 以 `index.md` 与卡片为准，不许凭印象 |
| **轨 5 空跑** | 库内不足 2 篇仍硬做综合 | 停在原地，报库内现有篇数并请用户补文献 |

## 14.8 各轨自查清单（收尾前过一遍）

**通用**：
- [ ] 本轮只出了一条轨？
- [ ] 菜单在拿到文献时无条件弹出（无豁免），且发出后停止、未自行代选？
- [ ] 切换提示行已附上？
- [ ] 零幻觉 / 两层隔离（铁律一、四）未被破坏？

**轨 1**：16 节逐节点名无缺节；术语表 5–8 条；资产对接个性化；800 字提炼在 700–900 字。
**轨 2**：摘要段数 N = A 轨条数；五大结构部分各 ≥1 段（或注明原文无此部分）；每段三字段齐全、译文无摘译；PID 台账完整。
**轨 3**：框架逐条点名"已查/原文未涉及"；每条批评有位置；P0/P1/P2 分级；打分口径按 ch13.6.3。
**轨 4**：静默底稿七字段齐（缺项已标注）；每个数字回原文核过；事实内核对照表逐条挂位置；演绎级无具体数字；无越界词（调查/导致/颠覆/首次）；边界段保留；对外文案无 PID 与 `[待核]`；播客禁公式、双人有交锋。
**轨 5**：开场声明纳入篇数与深浅；每条结论挂来源；无合并同类项、无跨篇外推；反证已写；缺席明说；按 ch16 §16.3 落卡（或用户明示不落）。

## 14.9 层级差异：五项不是平的（v1.8 新增）

菜单做成扁平的 1–5，是为了让用户"报数字"这一套心智不变；但内部必须按三个维度理解，否则会出现把五轨当同类处理的错：

| 维度 | 轨 | 关系 |
|---|---|---|
| **读法（同一篇的三种视角）** | 1 / 2 / 3 | 互斥；同篇一次一轨；靠 PID 衔接 |
| **语体转换（把已读的换副面孔）** | 4 | **依附**于 1–3 的成果；可与前面连做（"2，然后 4"）；**无底稿不许开写** |
| **综合（跨多篇）** | 5 | 与 1–4 **正交**；输入是多篇；需库内 ≥2 篇；**不读本篇** |

由此推出三条操作规则：

1. **"一次一轨"对五轨一律适用**——包括"4，然后 5"，也分两轮。
2. **轨 4 不构成新的阅读劳动**：它不重读原文，只做语体转换与对照表核对。所以"2 → 4"是自然的连做；"4 → 2"则要在轨 4 的静默底稿基础上补全领读。
3. **轨 5 不属本会话**：它读的是库，不是这篇。用户只给一篇文献时报 5，AI 要提醒"5 不读本篇"，避免用户误以为综合里会包含刚给的这篇（除非该篇已落卡）。
