# 读文献（du-wen-xian）

**Reading Literature** — 一个 Skill：拆解、精读、评估学术文献，把读懂的内容转成可发布的文案，并在多篇之间做综合。信息无损、逐节覆盖、零幻觉。

当前版本 **v1.8.1**（交付物为纯文本 Markdown，不生成图片）。

> **v1.8 变更**：由「强制三选一」扩为**强制五选一**——新增 **轨 4 传播转化**（推文 / 公众号摘要 / 演讲开场 / 邮件推荐 / 播客脚本）与 **轨 5 跨篇综合**（论文卡片知识库 + 多篇共性/分歧/演进），并新增**铁律六**（事实内核与修辞层分离）。详见下文与 `chapters/ch15`、`chapters/ch16`。

## 它做什么

给它一篇论文，它会先弹一张菜单让你选一种用法（**每轮只出一种**，因为上下文放不下五种）：

```
1 输出结构化的结果 —— 导语 + 身份卡 + 核心主张 + 论证链条 + 发现 + 术语 + 800 字提炼
2 通读论文       —— 摘要 100% 逐段 + 关键段落，逐段「原文 + 译文 + 解析」
3 评估论文质量   —— 五大框架 + 检查表 + 红线单 + 修改优先级（P0/P1/P2）
4 传播转化       —— 推文/公众号摘要/演讲开场/邮件推荐/播客脚本，必附事实内核对照表
5 跨篇综合       —— 库内多篇的共性、分歧与演进（需库内 ≥2 篇；本项不读本篇）
```

**五项不是同一层级**：1/2/3 是同一篇的三种**读法**（互斥，靠段落锚点 PID 衔接）；4 是读懂之后的**语体转换**（依附于 1–3，不能凭空写）；5 是**跨篇**（与 1–4 正交，读的是库）。

## 功能亮点

**轨 1–3（读与评）**

- **结构化速览**：身份卡含引用优先级 A/B/C 评级、200 字核心观点（引原文须外文+中文对照）、核心研究问题与子问题、作者研究脉络、研究设计六要点、关键发现、局限、创新性、后续推荐阅读 —— 每一栏都能追到原文位置。
- **全文领读**：先通读全文一遍，依据使用者研究画像决定关键段落的挑选侧重与术语解释深浅，按引言 / 文献回顾 / 研究设计 / 实证分析 / 讨论结论五大结构部分逐一挑选，逐段给「锚点 PID + 外文原文 + 完整中译 + 解析」。
- **质量评估**：按论文类型路由五大框架 —— 理论贡献（Whetten 1989 五要素+七问）、定量因果推断（Gangl 2010）、质性八项大帐篷标准（Tracy 2010）、质性报告完整性 SRQR 21 条（O'Brien et al. 2014）、评审者实际标准与学科文化差异（Lamont 2009）；输出总评、分框架检查表、红线问题单、P0/P1/P2 修改优先级。
- **方法路线**：三层精读法 + Keshav 三遍法（五C）+ 阅读密码表（Shon 14 密码）+ 论证五要素解剖（Booth）+ 定量十一条（Krippner）+ 质性 CASP 十问，按文献类型自动路由；专著、理论文本、综述各有专章。

**轨 4（传播转化，v1.8 新增）**

- 五种载体：社交短文案（小红书 / 微博 / 朋友圈，分别点明平台差异）、公众号·知乎长摘要（800–1200 字）、学术报告开场（30 秒，中英双版）、邮件推荐（分导师/同行两类对象）、播客脚本（单人解说 或 双人对话 × 短版/长版）。
- **事实内核对照表**：每份产物末尾必须附，逐条标 直引 / 转译 / 演绎 三级。数字、样本量、口径、变量方向、作者立场**一个字不许动**；演绎级句子**不得夹带具体数字**（防止读者把比喻里的数字当成原文数据）。
- 社科专属：长摘要必须交代**样本代表性边界**（访谈 36 人不能写成"大规模调查"，相关系数不能写成因果，某群体样本不能写成"中国青年"）。

**轨 5（跨篇综合，v1.8 新增）**

- **论文卡片知识库**：每读完一篇静默落一张 `card.md`（社科版模板含「理论对话对象 / 概念界定 / 可引原句 / PID 索引」四栏），深度分 速览 / 带读 / 已评 三档，只升不降。
- **跨篇综合**：定作用域 → 声明纳入篇数与深浅 → 先卡片后原文 → 综合 → 按需落 `syntheses/`；五种变体（找共性 / 找分歧 / 看演进 / 回忆 / 教学串联）。
- **双索引防串味**：每条结论挂 `→[篇名 · PID]`，仅据卡片的标 `〔据卡片〕`；禁止合并同类项、禁止跨样本外推，反证必写，缺席明说。

**通用纪律**

- **零幻觉铁律**：精读层严格限于所读文档既有内容，不编造、不推测作者动机；导读层（文献外背景）一律经检索核实并明示来源与查询时间。
- **个性化资产对接**：基于使用者研究画像，逐条标注每个批评点 / 遗漏点 / 待探讨问题可对接哪条研究线、哪篇稿件。

## 安装

### 方式一：对话内一句话安装

```
帮我安装这个skill: https://github.com/Cynthia-2028/du-wen-xian
```

### 方式二：用发布包（zip）

下载仓库里的 `dist/renwen-sheke-du-wenxian-v1.8.1.zip`，解压后把 `renwen-sheke-du-wenxian/` 整个文件夹放进你的 skills 目录：

| 客户端 | 目标目录 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/` |
| CodeBuddy / Claude Code | `~/.codebuddy/skills/` 或 `~/.claude/skills/` |
| Codex / Zcode / Trae | 各自的 skills 目录 |

解压后应看到 `renwen-sheke-du-wenxian/SKILL.md`，与 `chapters/`、`references/` 同级。

### 数据落位（轨 5 用）

跨篇综合需要一个论文库：

```
D:\WorkBuddyPlace\paper-library\
├── <slug>/card.md        # 论文卡片
├── <slug>/artifacts/     # 轨 4 产物（可选）
├── syntheses/            # 轨 5 综合
└── index.md              # 全库索引
```

首次使用会自动创建。路径可在 `SKILL.md` 的「知识库归档」小节与 `chapters/ch16` 中修改。

## 来源说明

轨 1–3 的方法论内容全部来自 `references/sources.md` 所列学术文献（Booth / Shon / Keshav / Laubepin / Krippner / CASP / Whetten / Gangl / Tracy / SRQR / Lamont / 董晨宇）。

**轨 4 与轨 5 属输出形态层与信息组织层，不新增学术方法论主张**；其工程实现改写自开源 skills `paper-glance`（模块 04_promo / 05_podcast）与 `paper-master`（cross-read / FORMATS），并做了社科语境本地化与 PID 双索引改造。引用时不得冒充学术文献。
